# Publishing guide: Malshan Cloud Credentials Portfolio

## GitHub setup

1. Sign in to GitHub as **Malshanshanuka**.
2. Create a new **public** repository named `cloud-credentials-portfolio` (do not pre-fill it with a README if you are uploading the package as-is).
3. Download and **unzip** `Malshan_Cloud_Credentials_Portfolio_GitHub_Ready.zip` first. GitHub will not automatically expand a ZIP uploaded to a repository.
4. Upload the **extracted files and folders** (including `README.md` and `index.html`) to the repository's root using **Add file → Upload files**. Keep `README.md` and `index.html` at the root and preserve the nested AWS PDF files.
5. Commit the files, then open the README to check every link.
6. Optional: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. After publication, your website will normally be at `https://malshanshanuka.github.io/cloud-credentials-portfolio/` (only after actually published).
7. Open the GitHub repository and GitHub Pages website in a signed-out/incognito browser to test the accessible links.

## CV wording and links

When the repository exists, use the clickable label **Cloud Credentials** linked to:
`https://github.com/Malshanshanuka/cloud-credentials-portfolio`

After GitHub Pages publication, you may instead use the clickable label **Cloud Portfolio** linking to:
`https://malshanshanuka.github.io/cloud-credentials-portfolio/`

Example CV line:

`CLOUD TRAINING | AWS Academy – Cloud Web Application Builder (Credly); AWS Training (6 completions); Microsoft Learn (14 achievements). [Cloud Credentials]`

If a one-page CV has little room, use:

`Cloud Training: AWS Academy badge · AWS & Microsoft Learn | [Cloud Credentials]`

Do not claim formal AWS Certified or Microsoft Certified qualification based only on these documents.

## Privacy

The Microsoft Learn URLs can reveal your Microsoft Learn account handle, which includes a student identifier. Review the URLs and public profile carefully before publishing. The AWS PDFs also include your full name by design.
