## Notes on evidence and privacy

- AWS course completion PDFs are provided under [`certificates/aws-training/`](certificates/aws-training/).
- Microsoft Learn entries link to the official achievement pages/print records shown in the uploaded PDFs, instead of uploading copies that expose the university/student account identifier in their printed certificate text.
- Some Microsoft Learn records may require the profile or achievement to be publicly visible. Test these links in a signed-out browser before sharing.

- This repository contains training evidence only. It does not imply professional production cloud experience.
